# Nidum AI Landing Page

A modern, responsive landing page for Nidum AI - showcasing intelligent AI solutions for businesses.

## Features

- 🎨 Modern, clean design with gradient aesthetics
- 📱 Fully responsive layout
- ⚡ Smooth animations and interactions
- 🎯 Clear call-to-action sections
- 💼 Professional business-focused content
- 🔧 No framework dependencies - pure HTML, CSS, and JavaScript

## Quick Start

1. Clone the repository
2. Open `index.html` in your browser, or
3. Run a local server:
   ```bash
   python3 -m http.server 51431
   ```
   Then visit `http://localhost:51431`

## Structure

- `index.html` - Main landing page
- `styles.css` - All styling and animations
- `script.js` - Interactive features and smooth scrolling

## Sections

1. **Hero Section** - Eye-catching introduction with animated AI visualization
2. **Features** - Six key features highlighting AI capabilities
3. **About** - Company information and statistics
4. **Solutions** - Industry-specific AI applications
5. **CTA** - Email capture and call-to-action
6. **Footer** - Links and company information

## Customization

- Colors can be modified in the CSS `:root` variables
- Content is easily editable in the HTML file
- Add your own logo and branding
